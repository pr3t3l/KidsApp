# Flujo UX — Plan semanal

**Estado:** Draft

## Entradas

- Participantes habituales o por día.
- Días y duración disponibles.
- Presupuesto de minutos por cada día elegido.
- Materiales críticos.
- Preferencias o restricciones temporales.

## Camino principal

1. El sistema propone una semana balanceada que llena aproximadamente el presupuesto de minutos de cada día con una o varias actividades.
2. Cada tarjeta muestra propósito, duración, preparación y razón.
3. El adulto puede cambiar día, sustituir o eliminar.
4. El sistema recalcula variedad sin bloquear ajustes manuales.
5. Se genera una lista consolidada: ya disponible, por reunir y opcional.
6. El plan queda publicado para la familia.
7. El paquete semanal se descarga con contenido, roles, objetivos, seguridad e imágenes.

## Criterios

- **UX-301:** Sustituir una actividad no reinicia el plan completo.
- **UX-302:** Se identifican materiales faltantes antes del día de ejecución.
- **UX-303:** El adulto puede cambiar participantes el mismo día.
- **UX-304:** La planificación no afirma certeza sobre disponibilidad del inventario aproximado.
- **UX-305:** La cantidad de actividades se deriva del tiempo y no es un objetivo por sí misma.
- **UX-306:** El adulto puede elegir 30, 60 u otro presupuesto soportado sin regenerar días no afectados.
